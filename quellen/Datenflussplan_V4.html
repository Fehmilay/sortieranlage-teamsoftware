Beispiel 1 – Klotz rot wird richtig aussortiert: I1 wird unterbrochen (S05) → Band läuft (S06) → Farbsensor misst kleinsten Wert 0,13 (S07) → „rot“ → 15 Impulse zählen (S08) → Kompressor (S10), Ventil rot 0,5 s (S11) → I3 wieder frei (S09) → Stückzahl +1 → MQTT: wert/farbe_letzte = rot, wert/anzahl_rot +1, event {"event":"sorted","color":"red"} (S12) → Peakboard: rote Kachel, Zähler rot +1 (S13).
Beispiel 2 – Störung „Band blockiert“: Band läuft, aber 2 s lang kein Impuls von C1 (S08) → Zustand FEHLER → Motor, Ventile, Kompressor sofort AUS (S06, S10, S11) → MQTT: wert/fehler_aktiv = 1, wert/fehler_text, event {"event":"error","code":"band_blockiert"} (S12) → Peakboard: rotes Störungsbanner (S13). Fällt Peakboard oder das Netz aus, sortiert die Anlage trotzdem weiter.

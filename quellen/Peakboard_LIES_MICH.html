★ PEAKBOARD – LIES MICH ZUERST (Marie + Jan)

Stand 03.11.2026. Hier steht alles, was ihr für das Peakboard braucht. Wenn ihr nur ein Dokument lest, dann dieses.

1. Worum geht es?

Unser Programm läuft auf dem Raspberry Pi und schickt seine Werte an das Postamt. Das Postamt ist der MQTT-Broker auf dem Pi. Das Peakboard holt die Werte dort ab und zeigt sie auf dem Bildschirm an: Zustand, Stückzahl, Farbe und Störung. Pi und Peakboard sprechen nie direkt miteinander, immer nur über das Postamt.

2. Stand jetzt

  • Die Verbindung steht. Auf dem Pi laufen gerade 2 Stunden lang Testdaten. Der Pi spielt eine sortierende Anlage vor. Es bewegt sich nichts, alles ist nur Simulation.
  • Die Daten kommen am Postamt an, das ist geprüft. Zustand und Stückzahl ändern sich laufend.
  • Ihr könnt also ab sofort das Peakboard mit echten Pi-Daten verbinden.

4. Diese Topics abonnieren

Jeder Wert hat ein eigenes Topic. Die Nachricht ist nur der Text oder die Zahl, kein JSON. Gesendet wird mit „retain“, das Peakboard bekommt also sofort den letzten Stand.

5. So geht es: zwei Wege

Weg A (schnell): die fertige Board-Datei ausprobieren

Claude hat ein Board vorgebaut: Sortieranlage_Board.pbmx. Achtung: Es wurde noch nie im Designer geöffnet. Genau das bitte zuerst testen.

  1. Datei von GitHub laden: github.com/Fehmilay/sortieranlage-teamsoftware → Ordner peakboard → Sortieranlage_Board.pbmx anklicken → „Download raw file“.
  2. Die Datei im Peakboard Designer öffnen.
  3. Links unter Data die Verbindung „Postamt Pi (Mosquitto)“ öffnen: Server 192.168.1.180, Port 1883. Benutzer und Passwort selbst eintragen.
  4. Vorschau bzw. Start im Designer: Die Werte müssen sich ändern.

So soll das Board aussehen: Vorschau-Bild auf GitHub

Weg B (falls A nicht klappt): Datenquelle von Hand anlegen (ca. 45 min)

  1. Im Designer: Data → Add data source → MQTT.
  2. Server 192.168.1.180, Port 1883, Benutzer und Passwort von Rushit.
  3. Unter Subscriptions die Topics aus Abschnitt 4 eintragen, QoS 0, Message type: Text.
  4. Enable listener, dann in der Vorschau prüfen, ob Werte ankommen.
  5. Kacheln anlegen und an die Werte binden (Bildschirm-Entwurf siehe unten).

Kommt bei Weg A eine Fehlermeldung, macht bitte einen Screenshot davon und legt ihn in „03 Bilder + Skizzen vom Team“.

7. Peakboard Box

Im Netz hängt ein Gerät mit der Adresse 192.168.1.81. Bitte am Bildschirm der Peakboard Box nachschauen, ob das ihre Adresse ist, und das Ergebnis eintragen. Das Board kommt erst auf die Box, wenn es im Designer läuft. Den Zugang zur Box gibt es ebenfalls bei Rushit.

8. Vor dem Gehen

  • Ergebnisse in die ★ KW-45-Tabelle eintragen: Öffnet die Datei (ja/nein)? Kommen Werte an (ja/nein)? Gab es eine Fehlermeldung? Was zeigt die Box als Adresse?
  • Den Pi nicht einfach ausstecken, das kann die Speicherkarte beschädigen. Stattdessen Rushit Bescheid geben („Pi aus“). Dann wird er sauber heruntergefahren, und nach 30 Sekunden darf der Stecker raus.
